# Lichtwerk

Foto-Finishing im Browser, gebaut fürs iPhone: Farb-Looks, Licht-Overlays, Atmosphäre (Nebel, Dunst, Rauch, Staub, Regen, Schnee), Text-Ebenen, Masken, Feinschliff und Export.

**App öffnen:** https://descentz111.github.io/lichtwerk/

Auf dem iPhone in Safari öffnen, dann Teilen › „Zum Home-Bildschirm“. Danach startet Lichtwerk wie eine App im Vollbild und funktioniert auch offline.

Alles läuft lokal im Browser – Fotos werden nirgendwo hochgeladen.
